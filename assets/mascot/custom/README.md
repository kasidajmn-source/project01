# ภาพมาสคอต (น้อง ENGY)

โฟลเดอร์นี้เก็บภาพมาสคอตที่ระบบใช้ ปัจจุบันคือ **น้อง ENGY** ของ กฟผ. (ภาพนิ่งจากชุดภาพทางการ ตัดขอบ ทำเป็นสี่เหลี่ยมจัตุรัส 360 × 360 พิกเซล และแปลงเป็น WebP)
ระบบทำให้ภาพขยับด้วย CSS ตามท่า (หายใจ โบกมือ ไหว้ กระโดดดีใจ เอียงคิด สั่นตกใจ) และใช้ **น้องดิ่ง** (ภาพวาดในระบบ) แทนเมื่อปิดชุดภาพหรือโหลดภาพไม่ได้

> หากเก็บระบบไว้ใน GitHub แบบสาธารณะ ภาพในโฟลเดอร์นี้จะเปิดดูได้โดยทุกคน — ใช้ตามสิทธิ์ที่หน่วยงานอนุญาต

## ท่าทางและจังหวะที่ใช้

| ท่า | ไฟล์ | ปรากฏตอน |
|---|---|---|
| `idle` (จำเป็น) | engy-idle.webp | ปุ่มไกด์ หน้าว่าง |
| `wave` | engy-wave.webp | เปิดแผงไกด์ ขั้นแรกของบทเรียน หน้าคู่มือ |
| `welcome` | engy-welcome.webp | หน้าแนะนำระบบ |
| `wai` | engy-wai.webp | ชวนเริ่มบทเรียน (สวัสดี) |
| `point` | engy-point.webp | ขั้น "ลองทำ" ในบทเรียน |
| `present` | engy-present.webp | ขั้นอธิบายในบทเรียน · ทักทายเมื่อยังไม่บันทึกรายงานประจำวัน |
| `cheer` | engy-cheer.webp | จบบทเรียน · บันทึกสำเร็จ |
| `ok` | engy-ok.webp | ทักทายเมื่อทุกโครงการเป็นไปตามแผน |
| `think` | engy-think.webp | ขั้นที่บัญชีนี้ไม่มีส่วนนั้น |
| `search` | engy-search.webp | ไม่พบหน้า |
| `oops` | engy-oops.webp | ไม่มีสิทธิ์ เกิดข้อผิดพลาด |
| `busy` | engy-busy.webp | ทักทายเมื่อมีเรื่องรอพิจารณา |
| `strong` | engy-strong.webp | ทักทายเมื่อมีโครงการล่าช้า (สู้ๆ) |
| `love` | engy-love.webp | เรียนครบทุกบทที่แนะนำ |
| `relax` | engy-relax.webp | วันอาทิตย์ที่ไม่มีงานค้าง |

ท่าที่ไม่มีไฟล์ระบบใช้ท่าใกล้เคียงแทน (เช่น `busy` → `think` → `idle`)

## ช่วงไว้ทุกข์

ตั้ง `"ribbon": true` ใน `mascot.json` ระบบจะใช้เฉพาะภาพติดริบบิ้นดำใน `ribbonPoses` (idle wave welcome point ok) และใช้ท่าใกล้เคียงจากชุดนี้สำหรับท่าอื่น — ตั้งกลับเป็น `false` เมื่อพ้นช่วง

## เปลี่ยน/เพิ่มภาพ

1. ภาพพื้นหลังโปร่งใส แนะนำสี่เหลี่ยมจัตุรัส 360 × 360 พิกเซล ตัวละครชิดขอบล่าง
2. ชนิดไฟล์ `.png` `.webp` `.svg` หรือ `.gif` · ชื่อไฟล์ใช้ได้เฉพาะ a–z A–Z 0–9 `_` `-` ยาวไม่เกิน 60 ตัวอักษร
3. วางไฟล์ในโฟลเดอร์นี้ แล้วแก้ชื่อไฟล์ใน `mascot.json` (`"enabled": true` และต้องมีท่า `idle`)
4. อัปโหลดขึ้นที่เก็บระบบแล้วรีเฟรช — ถ้าไฟล์ตั้งค่าผิดรูปแบบหรือภาพโหลดไม่ได้ ระบบใช้น้องดิ่งแทนโดยไม่ทำให้หน้าเสีย

ความปลอดภัย: ระบบรับเฉพาะ **ชื่อไฟล์** ในโฟลเดอร์นี้ (ไม่รับที่อยู่เว็บอื่น `../` หรือ `javascript:`) และแสดงผ่านแท็กภาพ `<img>` ซึ่งไม่รันสคริปต์ที่ฝังในไฟล์ SVG

ผู้ใช้แต่ละคนซ่อนมาสคอตได้ที่ **ตั้งค่า → บัญชีของฉัน → มาสคอต**
