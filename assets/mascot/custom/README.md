# ใส่ภาพมาสคอตของหน่วยงาน

ค่าเริ่มต้นของระบบคือ **น้องดิ่ง** (ลูกดิ่งสวมหมวกนิรภัย) ซึ่งเป็นตัวละครที่ออกแบบขึ้นใหม่สำหรับระบบนี้
ถ้าหน่วยงานได้รับอนุญาตให้ใช้ภาพมาสคอตของตนเอง (เช่น ภาพตัวละครทางการของ กฟผ.) ใส่แทนได้ที่โฟลเดอร์นี้
ระบบจะใช้ภาพเหล่านั้นในทุกจุดที่มาสคอตปรากฏ และขยับทั้งภาพตามท่าทาง

> ใช้เฉพาะภาพที่ได้รับอนุญาตจากเจ้าของลิขสิทธิ์ และหากเก็บระบบไว้ใน GitHub แบบสาธารณะ ภาพในโฟลเดอร์นี้จะเปิดดูได้โดยทุกคน

## ขั้นตอน

1. เตรียมภาพพื้นหลังโปร่งใส ขนาดแนะนำ 360 × 480 พิกเซล (สัดส่วน 3 : 4) อย่างน้อยหนึ่งภาพ
   - ชนิดไฟล์: `.png` `.webp` `.svg` หรือ `.gif`
   - ชื่อไฟล์ใช้ได้เฉพาะ a–z A–Z 0–9 `_` `-` ยาวไม่เกิน 60 ตัวอักษร เช่น `engy-wave.png`
2. คัดลอกภาพมาไว้ในโฟลเดอร์นี้ (`assets/mascot/custom/`)
3. แก้ไฟล์ `mascot.json` ในโฟลเดอร์นี้

```json
{
  "enabled": true,
  "name": "ชื่อมาสคอต",
  "poses": {
    "idle": "engy-idle.png",
    "wave": "engy-wave.png",
    "point": "engy-point.png",
    "cheer": "engy-cheer.png",
    "think": "engy-think.png",
    "oops": "engy-oops.png"
  }
}
```

| ท่า | ปรากฏตอน |
|---|---|
| `idle` (จำเป็น) | ยืนรอ บนปุ่มไกด์ หน้าว่าง |
| `wave` | ทักทายที่หน้าหลัก เปิดแผงไกด์ ชวนเริ่มบทเรียน |
| `point` | ชี้จุดที่ไฮไลต์ระหว่างบทเรียน |
| `cheer` | จบบทเรียน บันทึกสำเร็จ |
| `think` | หน้าค้นหาไม่พบ ขั้นตอนที่ต้องอธิบายเพิ่ม |
| `oops` | ไม่มีสิทธิ์ เกิดข้อผิดพลาด |

ท่าที่ไม่ได้ระบุจะใช้ภาพ `idle` แทน ถ้า `enabled` ไม่ใช่ `true` หรือไม่มีภาพ `idle` ระบบจะใช้น้องดิ่งตามเดิม

4. อัปโหลดขึ้นที่เก็บระบบ (เช่น GitHub) แล้วรีเฟรชหน้าเว็บ

ผู้ใช้แต่ละคนปิดมาสคอตได้ที่ **ตั้งค่า → การแสดงผล**
