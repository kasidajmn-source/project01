# ตราหน่วยงาน (โลโก้ กฟผ.)

ระบบจะแสดงตราหน่วยงานแทนเครื่องหมายเดิมที่ **แถบเมนูซ้าย หัวแถบบนมือถือ หน้าแนะนำระบบ และไอคอนแท็บเบราว์เซอร์ (favicon)** เมื่อมีไฟล์ในโฟลเดอร์นี้

## วิธีใส่โลโก้

1. ใช้ **ไฟล์ทางการ** ที่ได้รับจากหน่วยงานเท่านั้น (ไม่วาดหรือดัดแปลงตราเอง) — แนะนำ PNG พื้นโปร่งใส ขนาดอย่างน้อย 256 × 256 px หรือ SVG
2. ตั้งชื่อไฟล์เป็นภาษาอังกฤษ ตัวเลข `-` หรือ `_` เท่านั้น เช่น `egat-logo.png` (นามสกุล .png .svg .webp)
3. วางไฟล์ไว้ในโฟลเดอร์นี้ (`assets/brand/`)
4. แก้ `brand.json`:

```json
{
  "logo": "egat-logo.png",
  "alt": "กฟผ.",
  "favicon": true
}
```

- `logo` ชื่อไฟล์ (เว้นว่าง = ใช้เครื่องหมายเดิม)
- `alt` ข้อความแทนภาพสำหรับโปรแกรมอ่านหน้าจอ
- `favicon` ใช้ตราเป็นไอคอนแท็บเบราว์เซอร์ด้วยหรือไม่

5. (ถ้าติดตั้งเป็นแอปบนมือถือ/เดสก์ท็อป) แก้ `manifest.webmanifest` ส่วน `icons` ให้ชี้ไปที่ไฟล์เดียวกัน เช่น
   `{ "src": "assets/brand/egat-logo.png", "sizes": "512x512", "type": "image/png" }`

## ความปลอดภัย

- รับเฉพาะชื่อไฟล์ในโฟลเดอร์นี้ ไม่รับ path หรือ URL ภายนอก
- ภาพแสดงผ่านแท็ก `<img>` — สคริปต์ที่แฝงในไฟล์ SVG จะไม่ทำงาน
- ไฟล์เสียหรือหาไม่พบ ระบบใช้เครื่องหมายเดิมโดยอัตโนมัติ
- ตราสัญลักษณ์เป็นของ กฟผ. ใช้ภายในหน่วยงานตามระเบียบการใช้ตราของ กฟผ.
