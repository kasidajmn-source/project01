# คู่มือการเข้าใช้งานและการป้องกันสิทธิ์ (เวอร์ชัน 1.0.5)

> อ่านฉบับย่อได้ในเว็บ เมนู **คู่มือ** (`#/help`)

## 1. ใครเป็นอะไร

| ผู้ใช้ | ได้มาอย่างไร | ทำอะไรได้ |
|---|---|---|
| **ผู้ดูแลระบบ** | Google: บัญชีที่ติดตั้ง Apps Script (เสมอ) + รายชื่อในหน้าตั้งค่า · SharePoint: ผู้ที่กด "สร้างรายการข้อมูลในไซต์" + รายชื่อ · OneDrive: เจ้าของ OneDrive ที่เก็บโฟลเดอร์ (เสมอ) + รายชื่อ | ตั้งค่าที่เก็บข้อมูล กำหนดผู้บริหาร/ผู้ที่สร้างโครงการได้/เกณฑ์สี ดูและแก้ข้อมูลได้ทุกโครงการ ลบหรือโอนเจ้าของโครงการ — **ไม่พิจารณาอนุมัติแทน และไม่แต่งตั้งสมาชิกในโครงการที่มีเจ้าของ** |
| **ผู้บริหาร** | ผู้ดูแลระบบใส่อีเมลไว้ | ดูทุกโครงการ อ่านอย่างเดียว |
| **สมาชิกแผนก** | ผู้ดูแลระบบใส่อีเมลรายคน (ตั้งค่า → ผู้ใช้และสิทธิ์ของระบบ) | ดูทุกโครงการและความเคลื่อนไหว อ่านห้องสนทนาของโครงการอื่น (อ่านอย่างเดียว) คุยในห้องแผนก นัดประชุมแผนก |
| **เจ้าของโครงการ** | ผู้สร้างโครงการ (ต้องอยู่ใน "ผู้ที่สร้างโครงการได้") | ทุกอย่างในโครงการ และเป็น**ผู้เดียว**ที่แต่งตั้ง/ถอดถอนสมาชิก กำหนดสิทธิ์ ลำดับกรรมการ และขั้นตอนพิจารณา |
| สมาชิก | เจ้าของโครงการแต่งตั้งด้วยอีเมล | ตามบทบาท: ผู้ควบคุมงาน · คณะกรรมการ (มีลำดับ 1, 2, 3 … และประธาน) · ผู้รับจ้าง · หัวหน้า/ผู้บริหาร · ผู้ติดตาม |
| คนอื่น | — | **ไม่เห็นโครงการ** (Google: ขอรหัสเข้าระบบไม่ได้ ถ้ากำหนด "ผู้ที่สร้างโครงการได้" ไว้) |

**ลำดับเริ่มงาน:** ผู้ดูแลระบบตั้งค่าที่เก็บข้อมูล → ผู้สร้างโครงการสร้างโครงการ (= เจ้าของ) → เจ้าของแต่งตั้งสมาชิกในแท็บ **สมาชิกและสิทธิ์** (ระบบส่งอีเมลแจ้ง) → ส่ง **ลิงก์เชิญทีม** → สมาชิกเข้าระบบด้วยอีเมลที่ถูกแต่งตั้ง

## 2. วิธีเข้าใช้งาน

### Google Drive (Apps Script) — แนะนำเมื่อมีผู้รับจ้างภายนอก

**ผู้ดูแลระบบ (ครั้งแรก)**
1. สร้าง Google Sheet ในบัญชีที่จะเป็นเจ้าของข้อมูล → ส่วนขยาย → Apps Script → วางโค้ด `backend/Code.gs`
2. เลือกฟังก์ชัน `setup` → เรียกใช้ → อนุญาตสิทธิ์ (ดู Access key ในบันทึกการทำงาน)
3. ทำให้ใช้งานได้ → เว็บแอป: ดำเนินการในฐานะ **ฉัน**, ผู้ที่มีสิทธิ์เข้าถึง **ทุกคน** (การตรวจสิทธิ์อยู่ในโค้ด)
4. เปิดเว็บ → ตั้งค่า → Google Drive → ใส่ URL `/exec` + Access key → **บันทึกและเชื่อมต่อ**
5. หน้าต่างเข้าสู่ระบบ: ใส่**อีเมลบัญชีที่ติดตั้ง** → รับรหัส 6 หลักทางอีเมล → ใส่รหัส
6. ตั้งค่า → ผู้ใช้และสิทธิ์ของระบบ: "ผู้ใช้ใหม่ต้องลงทะเบียนและได้รับอนุมัติก่อน" เปิดอยู่ (1.0.15) — คนที่ยังไม่มีสิทธิ์ต้องยืนยันอีเมลและขอสิทธิ์ ดูข้อ 4.10
7. (ผู้ดูแลระบบ) กด **ลิงก์เชิญทีม** ส่งให้ทีม (ลิงก์มี Access key — ส่งเฉพาะคนในทีม) — **ลิงก์เว็บธรรมดาจะเปิดเป็นโหมดทดลองแยกกันทุกเครื่อง ไม่เห็นข้อมูลของทีม**
8. ถ้ามีข้อมูลในโหมดทดลองอยู่ก่อน: ตั้งค่า → **ย้ายข้อมูล** ขึ้น Google Drive

> ขึ้นข้อความ "คุณไม่ได้รับอนุญาตให้เรียกใช้ SpreadsheetApp…" = ยังไม่ได้ทำข้อ 2 (รัน `setup` และกดอนุญาต) หรือวางโค้ดใหม่แล้วยังไม่ได้รัน `setup` ซ้ำ → ทำข้อ 2 แล้ว Deploy เวอร์ชันใหม่

**ผู้ใช้ทั่วไป**
1. เปิด**ลิงก์ในอีเมลแต่งตั้ง/แจ้งเตือน** (1.0.11) หรือลิงก์เชิญทีม → ใส่ชื่อ → กด **เชื่อมต่อ** — ระบบเปิดหน้าโครงการ/เรื่องในอีเมลให้หลังเข้าสู่ระบบ
2. ใส่อีเมลที่เจ้าของโครงการแต่งตั้งไว้ → **ส่งรหัส** → นำรหัส 6 หลักจากอีเมลมาใส่ (ใช้ได้ 10 นาที ผิดได้ 5 ครั้ง ขอได้ 5 ครั้ง/ชั่วโมง)
3. อยู่ในระบบได้ 30 วันต่อเครื่อง · ออกจากระบบได้ที่ ตั้งค่า → บัญชีของฉัน

### SharePoint (Microsoft 365)

**ผู้ดูแลระบบ:** ขอฝ่าย IT ลงทะเบียนแอป (SPA) + Grant admin consent `Sites.ReadWrite.All`, `Sites.Manage.All` (+`Mail.Send`) → ตั้งค่า → SharePoint → ใส่ Tenant / Client ID / URL ไซต์ → **ลงชื่อเข้าใช้และตรวจสอบ** → **สร้างรายการข้อมูลในไซต์** (คุณจะเป็นผู้ดูแลระบบ) → **บันทึกและเชื่อมต่อ** → เพิ่มทีมเป็นสมาชิกไซต์ → ส่งลิงก์เชิญ

**ผู้ใช้ทั่วไป:** เปิดลิงก์เชิญ → **เชื่อมต่อ** → ลงชื่อเข้าใช้บัญชีองค์กรในหน้าต่าง Microsoft (อีเมลต้องตรงกับที่ถูกแต่งตั้ง) · ลงชื่อเข้าใช้ใหม่ทุก 24 ชั่วโมงตามนโยบาย Microsoft

### OneDrive

**ผู้ดูแลระบบ**
1. ลงทะเบียนแอป (SPA) สิทธิ์ `Files.ReadWrite`, `Files.ReadWrite.All` (+`Mail.Send`) — องค์กรส่วนใหญ่ต้องให้ IT กด **Grant admin consent** สำหรับ `.All`
2. ตั้งค่า → OneDrive → Client ID + ชื่อโฟลเดอร์ → **ลงชื่อเข้าใช้และตรวจสอบ** → **สร้างโฟลเดอร์ข้อมูล** → **บันทึกและเชื่อมต่อ**
3. หลังแต่งตั้งสมาชิก กด **ให้สิทธิ์เข้าถึงโฟลเดอร์** (แก้ไขได้ = ผู้ที่ต้องบันทึก / ดูอย่างเดียว = หัวหน้า ผู้ติดตาม ผู้บริหาร) แล้วส่ง **ลิงก์เชิญทีม**
4. ถอดสมาชิกแล้ว ให้ถอนสิทธิ์ใน OneDrive → โฟลเดอร์หลัก → จัดการการเข้าถึง ด้วย

**ผู้ใช้ทั่วไป:** เปิดลิงก์เชิญ → **เชื่อมต่อ** → ลงชื่อเข้าใช้บัญชี Microsoft ที่ได้รับแชร์ (ถ้าขึ้นว่าไม่มีสิทธิ์ ให้ผู้ดูแลกด "ให้สิทธิ์เข้าถึงโฟลเดอร์" ก่อน)

### โหมดทดลอง
ข้อมูลอยู่ในเบราว์เซอร์เครื่องเดียว **ไม่มีการป้องกันสิทธิ์จริง** (ปุ่ม "ทดลองใช้งานในนามผู้อื่น" ใช้ดูมุมมองของแต่ละบทบาท) — ใช้ฝึก แล้วย้ายข้อมูลขึ้นที่เก็บจริง

## 3. ลำดับการอนุมัติและการโหวต

1. **ผู้ควบคุมงาน** — คนใดคนหนึ่งพิจารณาได้
2. **กรรมการลำดับที่ 1 → 2 → 3 …** — ทีละคนตามลำดับ (คนถัดไปได้รับอีเมลเมื่อคนก่อนผ่าน)
3. **ประธานกรรมการ** — คนสุดท้าย

- เจ้าของโครงการกำหนดลำดับในตารางสมาชิก (ช่องลำดับใต้บทบาท "คณะกรรมการตรวจรับ") ลำดับซ้ำไม่ได้
- ขั้นคณะกรรมการของแต่ละหมวดเลือก "ทุกคนเรียงตามลำดับ" (ค่าเริ่มต้น จำนวนวัน = วันต่อคน) หรือ "คนใดคนหนึ่ง"
- ไม่ผ่านขั้นใด → ตีกลับผู้ส่ง (ต้องระบุเหตุผล) → ผู้ส่งแก้ไขส่งใหม่ → เริ่มขั้นแรก
- **โหวตเลือกรูปแบบ/สี** (แบบไม่ได้กำหนด): ผู้ส่งติ๊ก "ให้คณะกรรมการโหวต" ตอนส่งเรื่อง หรือผู้ควบคุมงานกด "เปิดให้คณะกรรมการโหวต" — ตัวเลือก 2–8 แบบ แนบรูปได้
  กรรมการโหวตคนละ 1 เสียง (เปลี่ยนได้จนปิด) · ครบทุกคน: เสียงข้างมากชนะ / เท่ากันใช้เสียงประธาน · ประธานหรือเจ้าของปิดโหวตก่อนครบได้ (คะแนนเท่ากันต้องเลือกชี้ขาด)
  ขั้นคณะกรรมการ/ขั้นสุดท้ายกด "ผ่าน" ได้หลังได้ข้อยุติ (กด "ไม่ผ่าน" ได้ตลอด)

## 4. ห้องสนทนาและการประชุม (1.0.4)

| ห้อง | อ่านได้ | พิมพ์ได้ |
|---|---|---|
| ห้องแผนก | สมาชิกแผนก ผู้บริหาร ผู้ดูแลระบบ | เหมือนกัน |
| ห้องโครงการ | สมาชิกโครงการ (รวมผู้รับจ้าง) + สมาชิกแผนก/ผู้บริหาร | สมาชิกโครงการ |
| ภายใน กฟผ. | สมาชิกโครงการที่ไม่ใช่ผู้รับจ้าง + สมาชิกแผนก/ผู้บริหาร | สมาชิกโครงการที่ไม่ใช่ผู้รับจ้าง |
| ห้องของการประชุม | ผู้เข้าประชุม และผู้ที่เห็นการประชุมนั้น | ผู้เข้าประชุม |

- **ประชุม**: ประชุมโครงการ (เชิญผู้รับจ้างได้) · ประชุมภายใน กฟผ. (เชิญผู้รับจ้างไม่ได้) · ประชุมแผนก — ผู้นัดได้: เจ้าของ/ผู้ควบคุมงาน/กรรมการ/หัวหน้าของโครงการ หรือสมาชิกแผนก (ประชุมแผนก)
- แก้ไขนัด บันทึกการประชุม และงานที่มอบหมาย: ผู้นัด เจ้าของโครงการ ผู้มีสิทธิ์แก้ไขโครงการ — ผู้รับผิดชอบงานติ๊กงานของตนว่าเสร็จได้
- Google: เซิร์ฟเวอร์กรองข้อความตามสิทธิ์ (ผู้รับจ้างไม่ได้รับข้อความห้องภายในเลย) · SharePoint/OneDrive: กรองที่หน้าเว็บ — ผู้ที่เปิดไฟล์/รายการข้อมูลตรงอ่านได้ทุกห้อง จึงไม่ควรใช้ห้องภายในคุยเรื่องลับเมื่อผู้รับจ้างมีสิทธิ์ในไซต์/โฟลเดอร์

## 4.2 หน้าแนะนำและภาพเคลื่อนไหว (1.0.6)

- ครั้งแรกที่เปิดเว็บจะพบ **หน้าแนะนำแบบเต็มจอ** — กรอกชื่อ/อีเมลแล้วเลือก "ลองด้วยข้อมูลตัวอย่าง" "เริ่มแบบว่าง" หรือ "เชื่อมต่อ Google Drive, SharePoint หรือ OneDrive" · เลื่อนลงหรือใช้แถบเมนูลอยด้านล่างเพื่อดูภาพรวม ขั้นตอน (บันทึก → อนุมัติ → รายงาน) และบทบาท
- เปิดหน้าแนะนำอีกครั้งได้จาก เมนู **คู่มือ › เปิดหน้าแนะนำระบบ** (ไม่กระทบข้อมูล)
- หน้าเว็บมีภาพเคลื่อนไหวเล็กน้อย: ตัวเลขผลงานนับขึ้น แถบผลงานเติมเต็ม และแถบเมนูลอยบนมือถือ (1.0.9 ลดเหลือเท่าที่ช่วยให้เห็นการเปลี่ยนแปลง) — **ตัวเลขสุดท้ายคือค่าจริงเสมอ**
- ปิด/เปิดได้ที่ **ตั้งค่า › บัญชีของฉัน › ภาพเคลื่อนไหว** (อัตโนมัติ / เปิด / ปิด) · "อัตโนมัติ" จะปิดเองเมื่อเครื่องตั้งค่า "ลดการเคลื่อนไหว" (Reduce motion) ไว้

## 4.3 ไกด์สอนการใช้งาน (1.0.7)

- **ผู้ใช้ใหม่**: ครั้งแรกที่เข้าหน้าใช้งาน (หลังหน้าแนะนำ หรือหลังเข้าสู่ระบบครั้งแรก) ระบบถามว่าจะ **เริ่มบทเรียน** หรือ **ข้ามไปก่อน** — ถามครั้งเดียว
- **ปุ่มไกด์มุมขวาล่าง** เปิดบทเรียนได้ทุกเมื่อ จุดสีส้มบนปุ่ม = ยังมีบทที่แนะนำที่ยังไม่ได้เรียน
- ระหว่างเรียน: หน้าจอมืดลงและไฮไลต์ทีละจุด · ขั้น **ลองทำ** ให้กดตรงที่ไฮไลต์เอง หรือกด **ทำให้ดู** · กด **ถัดไป/ย้อนกลับ** (หรือลูกศร ← →) · **ข้ามบทเรียน** ด้วยปุ่ม × หรือ Esc — บทเรียนไม่ส่งข้อมูลหรืออีเมลจริง

| บทเรียน | แนะนำสำหรับ | สอนอะไร |
|---|---|---|
| **สร้างโครงการแรก (ลงมือทำ)** (1.0.10) | ผู้ที่สร้างโครงการได้และยังไม่มีโครงการ | ทำจริงในฐานะผู้ควบคุมงาน: กรอกข้อมูลสัญญา → บันทึกโครงการ → พิมพ์ BOQ → บันทึกความคืบหน้าครั้งแรก → S-Curve → รายงานประจำวัน → เชิญทีม · ทุกช่องมีปุ่ม **ใส่ตัวอย่างให้** |

| เจ้าของโครงการ | ผู้สร้าง/เจ้าของโครงการ | สร้างโครงการ แต่งตั้งสมาชิก สิทธิ์ ขั้นตอนอนุมัติ BOQ เอกสารที่ต้องส่ง |
| ผู้ควบคุมงาน | ผู้ควบคุมงาน | บันทึกความคืบหน้า รายงานประจำวัน เปิดเรื่องและพิจารณาผ่าน/ไม่ผ่าน แบบฟอร์ม PT |
| ผู้รับจ้าง | ผู้รับจ้าง | ส่งเรื่องขออนุมัติ ติดตามผล เอกสารตามสัญญา ส่งใหม่เมื่อถูกตีกลับ ห้องสนทนา |
| คณะกรรมการตรวจรับ | กรรมการ/ประธาน | เรื่องรอพิจารณา ลำดับกรรมการ โหวตเลือกรูปแบบ/สี พิมพ์ใบขออนุมัติ |
| หัวหน้า/ผู้บริหาร | หัวหน้า ผู้บริหาร ผู้ติดตาม | สรุปผู้บริหาร โหมดนำเสนอ ส่งออก Excel รายงานประจำเดือน S-Curve |

- ถ้าบัญชีของคุณไม่มีปุ่มที่บทเรียนสอน (เช่น ยังไม่มีเรื่องรอคุณ) จะแสดงเป็นคำอธิบายแทน
- **สอนตามสิทธิ์จริง (1.0.10)**: บทของแต่ละบทบาทแสดงเฉพาะขั้นที่คุณมีสิทธิ์ในโครงการ (ตามที่เจ้าของโครงการตั้งในแท็บสมาชิกและสิทธิ์) และมีขั้น **สิทธิ์ของคุณในโครงการนี้** บอกว่ายังไม่มีสิทธิ์อะไร
- **ได้รับบทบาทใหม่ (1.0.10)**: เมื่อเจ้าของโครงการแต่งตั้งคุณเป็นบทบาทใหม่ ไกด์ชวนเรียนบทของบทบาทนั้นครั้งเดียว
- **บทสร้างโครงการแรก**: ขั้นที่มีป้าย **กรอก** ให้พิมพ์ในช่องที่ไฮไลต์ (Enter = ถัดไป) หรือกด **ใส่ตัวอย่างให้** · ขั้น **ลองทำ** ที่ต้องรอผล (เปิดแบบฟอร์ม/บันทึก) ไปต่อเองเมื่อทำสำเร็จ · โครงการฝึกลบได้ที่แท็บ **ตั้งค่า** ของโครงการ
- **โหมดทดลอง**: บทของบทบาทอื่นมีปุ่ม **ลองเป็น…** สลับไปใช้งานในนามสมาชิกตัวอย่างของบทบาทนั้น (กด “กลับเป็นตัวเอง” ที่แถบด้านบนเมื่อเสร็จ)
- ซ่อนปุ่มไกด์ หรือ **เริ่มบทเรียนใหม่** ได้ที่ ตั้งค่า › บัญชีของฉัน · รายการบทเรียนทั้งหมดอยู่ในหน้าคู่มือด้วย

## 4.7 แบบฟอร์มทางการ กฟผ. FM-001 / FM-002 (1.0.12)

ใช้รูปแบบตามเอกสาร **QP-CMD-MS-005** (ไม่มีตรา CONTROLLED) — กรอกข้อมูลจากระบบให้ แล้วพิมพ์ / บันทึกเป็น PDF

| แบบฟอร์ม | พิมพ์จาก | ระบบกรอกให้ | กรอกเองด้วยมือ |
|---|---|---|---|
| **FM-001** รายละเอียดผลการตรวจวัสดุก่อสร้าง | หน้าเรื่องขออนุมัติหมวดวัสดุ (ปุ่ม FM-001) · รายงานประจำวัน › ⋯ › ผลการตรวจวัสดุ · คลังแบบฟอร์ม | งาน สถานที่ เลขที่งาน ผู้รับจ้าง สัญญา วัสดุ วันที่ ผู้ควบคุมงาน | จำนวนนำเข้า/สุ่มตรวจ มาตรฐาน ผลการตรวจ ลายมือชื่อ |
| **FM-002** บันทึกการควบคุมงานประจำวัน | รายงานประจำวัน › ⋯ › พิมพ์ FM-002 · คลังแบบฟอร์ม (ฉบับเปล่า) | หัวฟอร์มทั้งหมด งาน/ปริมาณ ปัญหา การแก้ไข วัสดุ คน เครื่องจักร | ลายมือชื่อ |

- ใส่ **แผนก/กอง/ฝ่าย · เลขที่งาน (PM-Order กอง) · ผู้แทนผู้รับจ้าง** ที่ แท็บตั้งค่าโครงการ › ข้อมูลหัวแบบฟอร์ม กฟผ. ครั้งเดียว ใช้กับทุกฉบับ
- รายงานประจำวัน: เขียนงานทีละบรรทัด ลงท้ายด้วยปริมาณและหน่วย (เช่น `เทคอนกรีตเสาตอม่อ C1–C8 6.4 ลบ.ม.`) ระบบแยกลงช่อง "ปริมาณงาน" ให้ · วัสดุ คน เครื่องจักร เขียนแบบเดียวกัน
- พิมพ์: หน้าต่างพิมพ์ของเบราว์เซอร์ เลือก **A4 · ระยะขอบ: ไม่มี (None) · ไม่พิมพ์หัว/ท้ายกระดาษ** — ระยะขอบอยู่ในแบบฟอร์มแล้ว
- ต้องการฉบับต้นฉบับไปกรอกด้วยมือ: หน้า **แบบฟอร์มและระเบียบ** › ต้นฉบับ กฟผ. (PDF ไม่มีตรา CONTROLLED) — FM-001 · FM-002 · QP-CMD-MS-005 ทั้งชุด

## 4.8 กรอกแบบฟอร์มบนเว็บแล้วบันทึก PDF (1.0.13)

ทุกแบบฟอร์มในระบบเปิดเป็นหน้ากระดาษ A4 ที่ **กรอกได้เลย** — ไม่ต้องพิมพ์ออกมาเขียนด้วยมือ

1. เปิดแบบฟอร์ม: จากจุดที่ใช้งาน (เรื่องขออนุมัติ รายงานประจำวัน การประชุม) หรือหน้า **แบบฟอร์มและระเบียบ** — เลือกโครงการและ **ข้อมูล ณ วันที่** (ค่าเริ่มต้นวันนี้) แล้วกดแบบที่ต้องการ
2. คลิกช่องที่มีพื้นสีฟ้าอ่อนแล้วพิมพ์ · **Enter** ไปช่องถัดไป · **Shift+Enter** ขึ้นบรรทัดใหม่ในช่องเดิม
3. **วันที่**: คลิกเพื่อเลือกจากปฏิทิน — ตั้งเป็นวันนี้ไว้ให้แล้ว เปลี่ยนได้ทุกช่อง (กด Delete เพื่อเว้นว่าง)
4. ช่องสี่เหลี่ยม: คลิกเพื่อติ๊ก · PT-F07: คลิกช่องรูปเพื่อเลือกรูป หรือลากรูปมาวาง · ตัวเลขคนงาน/เครื่องจักรรวมให้เอง
5. กด **ดูแบบพิมพ์** เพื่อดูหน้าตาจริง แล้วกด **บันทึก PDF / พิมพ์** → ปลายทาง "บันทึกเป็น PDF" (มือถือ: แชร์ › บันทึกเป็นไฟล์)

- ที่กรอกไว้ **จำในเครื่องนี้** — ปิดหน้าต่างแล้วเปิดแบบเดิมของเรื่อง/วันเดียวกัน กรอกต่อได้ · กด **ล้างที่กรอก** (สองครั้ง) เพื่อเริ่มจากข้อมูลในระบบ
- ข้อความที่แก้ในแบบฟอร์มไม่เปลี่ยนข้อมูลในระบบ — แก้ข้อมูลจริงที่หน้ารายงาน/เรื่องนั้น
- **PT-F01 หนังสือขออนุมัติ**: หน้า 1 หนังสือ (หัวจดหมายเป็นชื่อผู้รับจ้าง ไม่มีโลโก้) · หน้า 2 ตารางสิ่งที่เสนอเทียบข้อกำหนดในสัญญา · หน้า 3 ช่องพิจารณา — เปิดจากเรื่องที่พิจารณาแล้วจะติ๊กผล ใส่ชื่อ ความเห็น และวันที่ให้
- **PT-F07 Daily Report and Daily Request**: วันที่ Daily Request เลื่อนตามวันที่รายงานเอง · ความคืบหน้าคิด ณ วันที่รายงาน (เปลี่ยนวันที่คำนวณได้ที่ "ข้อมูล ณ วันที่" ก่อนเปิด)

## 4.9 กรอกครั้งเดียว · ลายมือชื่อ · มาร์คบนรูป · รายงานสัปดาห์ (1.0.14)

**รายงานประจำวัน = แบบฟอร์ม** — กรอกในหน้ารายงานประจำวันครั้งเดียว แบบ FM-002 · PT-F07 · รายงานประจำสัปดาห์ และ S-Curve ดึงไปเอง

| ช่องในรายงานประจำวัน | ไปอยู่ที่ |
|---|---|
| อากาศเช้า/บ่าย · กลางคืน · PM2.5 | FM-002 สภาพอากาศ · PT-F07 หัวฟอร์ม |
| งานที่ดำเนินการ (รายละเอียด / ปริมาณ / หน่วย) | FM-002 รายละเอียดของงาน + ปริมาณงาน · PT-F07 Daily Report |
| ปริมาณงานตาม BOQ | บันทึกความคืบหน้าของวันนั้น → ผลงาน % · S-Curve · รายงานสัปดาห์ · PT-F07 Yesterday/Accum. Qty |
| งานที่ผู้รับจ้างขอทำวันถัดไป | PT-F07 Daily Request (ปริมาณ ช่าง/คนงาน) |
| ผู้ปฏิบัติงาน · เครื่องจักร · วัสดุ | FM-002 · PT-F07 (คนงานสะสม Upto last day / To day / Accumulate) |
| ภาพประกอบ (ลำดับ + คำบรรยาย) | FM-002 หน้าแนบท้าย · PT-F07 ภาพประกอบการทำงาน "รูปที่ n …" |

- **คำแนะนำ**: คำใหม่ (เช่น ชื่อตำแหน่ง เครื่องจักร วัสดุ) ที่ใช้ในโครงการเดียวกันครบ 3 วัน ระบบจำเป็นคำแนะนำในช่องค้นหาให้เอง
- **เรื่องขออนุมัติ**: ส่วน "ข้อมูลหนังสือขออนุมัติ (PT-F01)" ใส่ตารางสิ่งที่เสนอ เอกสารแนบ ประเภทงาน — เปิดเองเมื่อเลือกหมวดวัสดุ/แบบ
- **มาร์คบนรูป**: ทุกจุดที่เลือกรูปมีปุ่ม "มาร์ค" — วาด ลูกศร กรอบ วงกลม เขียนข้อความ แล้ว "ใช้รูปนี้"
- **ลงลายมือชื่อ**: คลิกช่องลงชื่อ (✎) ในแบบฟอร์ม → วาด / เลือกรูป / ลากรูปมาวาง · ติ๊ก "จำลายเซ็นไว้ในเครื่องนี้" แล้วครั้งต่อไปกดใช้หรือลากป้ายลายเซ็นบนแถบด้านบนไปวาง — อย่าจำลายเซ็นบนเครื่องที่ใช้ร่วมกัน
- **ปฏิทิน**: คลิกนอกกรอบ หรือกด Esc เพื่อปิด
- **รายงานประจำสัปดาห์**: เลือก "สัปดาห์ที่" บนแถบด้านบนของแบบฟอร์ม — มีกราฟ S-Curve และเปอร์เซ็นต์ตามหมวดงาน BOQ

## 4.10 ลงทะเบียนขอสิทธิ์ · Daily Report ของผู้รับจ้าง · ค่าที่พัก/เดินทาง · PDF รายงาน (1.0.15)

**ลงทะเบียนขอสิทธิ์ (Google Drive)**
1. ผู้ใช้ใหม่เปิดลิงก์เชิญทีม → ใส่อีเมล → ใส่รหัส 6 หลักจากอีเมล
2. ถ้ายังไม่มีสิทธิ์ ระบบเปิด**แบบขอสิทธิ์**: ชื่อ · ตำแหน่ง · (คนของโครงการ) โครงการและขอบเขตงาน · หน่วยงาน/บริษัท · โทรศัพท์ · หมายเหตุ — อีเมลโดเมนขององค์กร (เช่น @egat.co.th) เลือกโครงการจากรายการ · คนนอก (ผู้รับจ้าง อีเมลส่วนตัว) **ไม่เห็นรายชื่อโครงการ** ต้องพิมพ์**รหัสโครงการ**ที่ได้จากผู้ควบคุมงาน
3. ผู้อนุมัติได้อีเมล "คำขอสิทธิ์" → กด **พิจารณาคำขอ** → อนุมัติ / ไม่อนุมัติ (ใส่เหตุผล)

| ตำแหน่งที่ขอ | ผู้อนุมัติ | ได้สิทธิ์ |
|---|---|---|
| ผู้ควบคุมงาน | ผู้ดูแลระบบ | สร้างและดูแลโครงการของตนเอง |
| ผู้บริหาร | ผู้ดูแลระบบ | ดูทุกโครงการ (อ่านอย่างเดียว) |
| ผู้รับจ้าง · คณะกรรมการตรวจรับ · หัวหน้าโครงการ · ผู้ติดตาม | ผู้ควบคุมงานที่สร้างโครงการ | สมาชิกโครงการตามตำแหน่ง (เปลี่ยนภายหลังได้ที่หน้าสมาชิก) |

- อนุมัติในเว็บ: ผู้ดูแลระบบ → ตั้งค่า › การลงทะเบียนขอสิทธิ์ · เจ้าของโครงการ → โครงการ › สมาชิกและสิทธิ์ (แท็บมีเครื่องหมาย ! เมื่อมีคำขอ)
- ลิงก์ในอีเมลใช้ได้ครั้งเดียว 14 วัน — **อย่าส่งต่ออีเมลคำขอสิทธิ์**

**ข้อมูลคลาวด์และผู้ดูแล — เฉพาะผู้ดูแลระบบ** — ผู้ใช้อื่นเห็นในหน้าตั้งค่าเพียงสถานะการเชื่อมต่อและปุ่มดึงข้อมูลล่าสุด ไม่เห็นที่อยู่ระบบหลังบ้าน รหัสเข้าใช้งาน โฟลเดอร์ ลิงก์เชิญทีม และรายชื่อผู้ดูแล/ผู้สร้างโครงการ · ผู้ควบคุมงานเชิญคนเข้าโครงการด้วยการเพิ่มสมาชิกในแท็บสมาชิก (ระบบส่งอีเมลพร้อมลิงก์ให้เอง) · ผู้ดูแลที่ใช้เครื่องใหม่ให้เปิดลิงก์เชิญทีมของตัวเอง หรือกด "ตั้งค่าการเชื่อมต่อใหม่" แล้วพิมพ์ที่อยู่และรหัสใหม่

**Daily Report & Request ของผู้รับจ้าง (PT-F07)**
- ผู้รับจ้าง: แท็บรายงานประจำวัน → "บันทึก Daily Report & Request วันนี้" → งานที่ทำได้ (เลือกหมวด/รายการ BOQ) งานที่ขอทำวันถัดไป คนงาน เครื่องจักร รูป
- ผู้ควบคุมงาน: แท็บย่อย "Daily Report & Request ผู้รับจ้าง" ดูทุกฉบับ · ในรายงานของตนกด "ดึงข้อมูลจากรายงานผู้รับจ้าง" · ผู้รับจ้างไม่เห็นรายงานของผู้ควบคุมงาน

**งานที่ดำเนินการตามรายการ BOQ** — เลือกหมวด → รายการ → ใส่ปริมาณ (หน่วยตาม BOQ) คำบรรยายพิมพ์เองได้ · ปริมาณของรายงานผู้ควบคุมงานเป็นความคืบหน้าของวันนั้น

**ค่าที่พัก / ค่าเดินทาง** — ผลงาน = ½ × (วันที่มีผู้ปฏิบัติงานเข้างาน ÷ วันตามสัญญา) + ½ × ความคืบหน้าของงานอื่น · งานอื่นเสร็จ = 100% · ตั้ง/ยกเลิกได้ที่ แก้ BOQ › "นับผลงาน"

**ไฟล์ PDF ของรายงาน** — ติ๊ก "เก็บเป็นไฟล์ PDF" ตอนบันทึก (ค่าเริ่มต้น) → ไฟล์อยู่แท็บเอกสาร หมวด "รายงานประจำวัน/สัปดาห์" · ลงลายมือชื่อ: "เพิ่มลายมือชื่อในไฟล์" หรือเมนู "เปิดแบบฟอร์มเพื่อลงชื่อ" แล้วกด "บันทึกเข้าเอกสาร"

## 4.11 ความคืบหน้าในรายงานประจำวัน · แบบฟอร์มฉบับเดียวกันทุกหน้า (1.0.16)

**ระบุความคืบหน้าในรายงานประจำวัน** (แบบฟอร์มที่พิมพ์หน้าตาเหมือนเดิม)
- โครงการที่มี BOQ: แต่ละแถวงานเลือกรายการ BOQ แล้วกรอก**ปริมาณของวันนี้** หรือ **% สะสม** ของรายการ (ช่องขวาสุด) — กรอกช่องหนึ่ง อีกช่องคำนวณให้ เช่น รายการก่อนหน้าทำได้ 40% วันนี้ใส่ 45% → ปริมาณวันนี้ = 5% ของปริมาณ BOQ
- เกิน 100% ได้เฉพาะโครงการที่ตั้ง "ยอมให้ปริมาณเกิน BOQ" · ใส่ต่ำกว่าที่ทำได้แล้ว ช่องจะเป็นสีแดงและปริมาณวันนี้ = 0
- โครงการที่คิดความคืบหน้าแบบ**กรอก % เอง** หรือยังไม่มี BOQ: มีช่อง **ความคืบหน้ารวมของโครงการ ณ วันนี้ (%)** ในรายงาน
- บันทึกรายงาน (ผู้ควบคุมงาน) → ความคืบหน้าของโครงการ กราฟ S-Curve และรายงานประจำสัปดาห์อัปเดตให้ทันที · แก้/ลบรายงาน = แก้/ลบความคืบหน้าที่ผูกกันด้วย
- Daily Report ของผู้รับจ้างกรอก % ได้เหมือนกัน แต่ไม่เปลี่ยนความคืบหน้าของโครงการจนกว่าผู้ควบคุมงานดึงไปใส่ในรายงานของตน

**แบบฟอร์มฉบับเดียวกันทุกหน้า**
- หน้ารายงานในโครงการมีปุ่ม **แบบฟอร์ม FM-002 / PT-F07** (ค่าเริ่มต้นบนคอมพิวเตอร์) — แสดงแบบฟอร์มเดียวกับหน้าต่างแบบฟอร์มและไฟล์ PDF · ปุ่ม **ข้อมูลรายงาน** แสดงข้อมูลแบบเดิม
- หน้า "แบบฟอร์มและระเบียบ" เลือกโครงการ + วันที่ แล้วกด FM-002 หรือ PT-F07 → เลือก
  - **รายงานของโครงการ** — ฉบับเดียวกับในโครงการ (ข้อมูล ร่างที่กรอก และปุ่ม "บันทึกเข้าเอกสาร" ชุดเดียวกัน)
  - **สำเนาสำหรับใช้ภายนอก** — ดึงข้อมูลมาใส่ แก้ได้อิสระ ไม่บันทึกกลับเข้าโครงการ (แถบด้านบนเป็นสีเหลือง)
  - **แบบเปล่า มีหัวกระดาษของโครงการ**
- แก้รายงานหลังเคยกรอกในหน้าต่างแบบฟอร์ม → แบบฟอร์มใช้ข้อมูลล่าสุดของรายงานในช่องที่เปลี่ยน ส่วนที่พิมพ์เพิ่มเองและลายมือชื่อยังอยู่
- แก้รายงานหลังสร้างไฟล์ PDF → หน้ารายงานเตือน "ไฟล์ PDF สร้างก่อนแก้ไขรายงานครั้งล่าสุด" พร้อมปุ่มสร้างไฟล์ใหม่

**รหัสโครงการ** — ถ้าพิมพ์ตอนแป้นเป็นภาษาไทย (เช่น "่ดนไ่ด") ระบบเตือนในหน้าภาพรวมและตั้งค่าโครงการ พร้อมปุ่มแปลงเป็นตัวอักษรอังกฤษ — รหัสนี้ไปอยู่ในหัวอีเมลและชื่อไฟล์ทุกฉบับ

## 4.12 แบบผนวกท้ายสัญญา · งวดงาน · ป้ายโครงการ (1.0.17)

**งวดงานและแผนการเบิกจ่าย** — ตั้งค่าโครงการ › งวดงานและแผนการเบิกจ่าย: เพิ่มงวด (หรือแบ่งเท่ากัน) ใส่รายละเอียดงานของงวด ร้อยละของงาน ร้อยละการเบิก (ว่าง = เท่ากับร้อยละของงาน) และวันที่ผลงานถึงเกณฑ์ → ระบบคำนวณราคาต่องวดและยอดสะสมจากมูลค่าสัญญา · รวมไม่เท่ากับ 100% จะเตือนสีแดง · กด "บันทึกการตั้งค่า"

**ใบส่งงวดงาน F-04-03-09** — เปิดจากเรื่อง "ส่งมอบงาน/ขอตรวจรับงวดงาน" (ชื่อเรื่องมี "งวดที่ 2" ระบบเลือกงวดให้) หรือหน้าแบบฟอร์ม → เลือกงวดที่บนแถบด้านบน → ผลงานครั้งนี้ รวมทั้งสิ้น หัก 10% คงเหลือเบิก คำนวณให้ · งวดสุดท้ายติ๊ก "งวดสุดท้าย" ให้

**ตารางแผนงานก่อสร้าง F-04-03-07** — หมวด BOQ เป็นแถว ร้อยละของงานตามวิธีคิดความคืบหน้าของโครงการ · แถบเวลาจากแผนรายรายการใน BOQ (คลิกช่องเพื่อระบาย/ลบได้) · ราคางานและ % ผลงานที่คาดหมายแต่ละเดือน/สะสม พร้อมเส้น S-Curve จากแผนงานในตั้งค่าโครงการ · คอลัมน์เดือน: สัญญาไม่เกิน 6 เดือน = รายสัปดาห์ · ไม่เกิน 15 เดือน = ครึ่งเดือน · นานกว่านั้น = รายเดือน

**ตารางแผนงานความปลอดภัย F-04-03-08** — พิมพ์กิจกรรม (มีคำแนะนำ เช่น Toolbox Talk ตรวจ PPE ซ้อมแผนฉุกเฉิน) แล้วคลิกช่องเดือนเพื่อระบาย

**หนังสือรับรองการเป็นวิศวกร/สถาปนิก** — ชื่อผู้รับจ้างและชื่องานใส่ให้ แนบกับเรื่องขออนุมัติพร้อมสำเนาใบอนุญาต (ใบอนุญาตต้องมีอายุครอบคลุมจนงานแล้วเสร็จ)

**ป้ายโครงการ** — ตั้งค่าโครงการ › ปุ่ม "ป้ายโครงการ" (หรือหน้าแบบฟอร์ม / เอกสารที่ต้องส่ง)
- ชื่องาน ผู้รับจ้าง ราคางาน สัญญาเลขที่ ระยะเวลา วันเริ่ม/สิ้นสุด และผู้ควบคุมงาน ดึงจากโครงการ (แก้ที่ตั้งค่าโครงการ) · กรอกเพิ่ม: ที่อยู่/โทรศัพท์ผู้รับจ้าง ตัวแทน วิศวกร จป. โทรศัพท์ผู้ควบคุมงาน สำนักงานสนาม → "บันทึกข้อมูลป้าย" (ทีมใช้ร่วมกัน)
- ขนาดตามหมายเหตุในตัวอย่างป้าย: ราคางานไม่เกิน 50 ล้านบาท 1.20 × 2.40 ม. · เกิน 50 ล้านบาท 2.40 × 4.80 ม. · งานภายในอาคาร 0.60 × 1.20 ม. · พื้นสีน้ำเงิน ตัวอักษรและกรอบสีขาว
- **PDF ขนาดจริง** (ส่งร้านทำป้ายได้เลย ภาพไม่บีบอัดแบบสูญเสีย ประมาณ 100 dpi ที่ 2.40 ม.) และ **PNG**
- **ตรา กฟผ.** — ระบบไม่วาดตราเอง: ใช้ตราหน่วยงานของระบบ (ผู้ดูแลวางไฟล์ทางการใน `assets/brand`) หรือกด "เลือกไฟล์ตราทางการ" (เครื่องจำไว้ให้) · ไม่มีตรา = เว้นช่องไว้ให้ร้านทำป้ายใส่
- งานที่ยาว เช่น ถนน รางระบายน้ำ ติดตั้งที่จุดเริ่มต้นและจุดสิ้นสุด อย่างน้อย 2 จุด

## 4.5 ตราหน่วยงาน — โลโก้ กฟผ. (1.0.10)

- วาง **ไฟล์ตราทางการ** (PNG พื้นโปร่งใส ≥ 256 px หรือ SVG ชื่อไฟล์ภาษาอังกฤษ เช่น `egat-logo.png`) ในโฟลเดอร์ `assets/brand/`

- **SharePoint / OneDrive**: หน้าเว็บตรวจสิทธิ์ก่อนบันทึก และ Microsoft ตรวจสิทธิ์ของไซต์/โฟลเดอร์ — ผู้ที่มีสิทธิ์**แก้ไข**ไซต์/โฟลเดอร์สามารถเปิดข้อมูลแก้ตรงด้วย SharePoint/OneDrive ได้ จึงควรให้สิทธิ์แก้ไขเฉพาะคนในองค์กรที่ไว้ใจได้ และให้หัวหน้า/ผู้ติดตามเป็น "ดูอย่างเดียว" (OneDrive ทำให้อัตโนมัติด้วยปุ่ม "ให้สิทธิ์เข้าถึงโฟลเดอร์") · OneDrive/SharePoint เก็บประวัติเวอร์ชันให้ตรวจย้อนหลังและกู้คืนได้

**ข้อควรปฏิบัติ**
1. กำหนด **ผู้ที่สร้างโครงการได้** (เช่น `@egat.co.th`) และ **ผู้ดูแลระบบ** ให้ชัดเจนตั้งแต่วันแรก
2. ลิงก์เชิญของ Google มี Access key — ส่งเฉพาะคนในทีม ถ้าหลุดให้รัน `resetAccessKey` แล้วส่งลิงก์ใหม่ · ให้ทุกคนออกจากระบบ: `logoutEveryone`
3. ถอดสมาชิกที่พ้นหน้าที่ออกจากโครงการทันที (มีผลทันที — ผู้ที่ถูกถอดจะไม่เห็นโครงการนั้นอีก) และ OneDrive: ถอนสิทธิ์โฟลเดอร์ด้วย
4. ออกจากระบบทุกครั้งบนเครื่องสาธารณะ · อย่าแก้คอลัมน์ `Data` หรือไฟล์ใน `_data` ด้วยมือ
5. ผู้รับจ้างภายนอกเห็นข้อมูลทั้งหมด**ของโครงการตน** (BOQ ความคืบหน้า เอกสาร) — ถ้ามีข้อมูลภายในที่ไม่ควรเปิดเผย ให้เก็บนอกระบบ หรือใช้โครงการแยก

| Google: แนบไฟล์โดยอ้างรหัสเรื่องของโครงการอื่นได้ | ตรวจว่าเรื่องอยู่ในโครงการเดียวกัน |
| Google: ส่งค่า "ผู้สร้าง/วันที่สร้าง" ของโครงการเองได้ | ใช้ค่าเดิมจากเซิร์ฟเวอร์เสมอ |
